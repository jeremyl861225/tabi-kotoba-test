描述（上限 4000 字）

Typeday 是一本打字機風格的手帳：每天、每週要做的事，一次性的行程，還有要花好幾天完成的任務，都整齊排在同一張紙上。打勾的時候，就像在打字機上敲下一個 [x]。

■ 四個頁面
・重複排程：每日、每週、每月（例如每月 15 號、每月第二個星期三），或自訂每幾天、每幾週、每幾個月。下一次是哪天自動算好，點狀節奏條一眼看出接下來四週哪幾天要做。
・月曆：每天的小記號告訴你那天有什麼；點一天，當天要做的事全部列出來，直接打勾。
・近期任務：有截止日的大任務拆成子任務，做完一步勾一步，完成度一看就知道。
・未完成：過去沒勾到的事自動集中到這裡，可以補勾，或把這一次挪到別天。

■ 小地方
・重要的事標成「重大事件」，在清單裡特別顯眼。
・類別用顏色區分；每件事都能寫敘述、放相關連結、加子事項。
・兩種外觀：打字機（等寬字、格線紙、中括號勾選框）與糖果紙（圓角卡片、手繪螢光筆、會彈跳的勾選框）；淺色、深色或跟著系統。
・第一次打開有互動教學，跟著點一遍就會用。

■ 資料只在你這邊
・不用註冊帳號，沒有廣告，不追蹤；我們沒有伺服器，看不到你的資料。
・自動備份：每天自動存一份到你選的資料夾（建議選 iCloud 雲碟），保留最近 30 份。刪掉 App、換手機，資料都還在。
・隨時可以匯出成 JSON 檔，也能從備份檔匯入還原。

■ 完整版（App 內購買，一次買斷，沒有訂閱）
・桌面小工具：大、中、小三種，以及鎖定畫面三種；點某一天直接打開那天。
・鎖定畫面週曆桌布：搭配「捷徑」每天自動換上本週週曆，也可以用自己的照片當底。
・糖果紙外觀。
除了上面三項，其他功能都免費，事項數量也沒有限制。

Typeday is a planner for recurring routines, events and tasks. No account or login is required; all data is stored on the device, and the app has no server and no third-party SDKs.

On first launch an interactive tutorial walks through the main pages (it can be skipped). Tap the + button to add a recurring schedule, an event or a task.

In-app purchase "Typeday Full Version" (non-consumable) unlocks:
1. Home Screen and Lock Screen widgets.
2. The Shortcuts action "產生週曆桌布" (Generate Weekly Wallpaper) for a Lock Screen weekly calendar wallpaper.
3. The "Candy" (糖果紙) appearance.
To open the purchase screen: tap the ⋮ menu (top right) → 完整版 (Full Version). "Restore Purchases" (恢復購買) is on the same screen. Without the purchase, a widget shows an "unlock" message that opens this screen. All other features are free with no limits.

Backup: ⋮ → 自動備份 (Auto Backup) lets the user pick a folder in Files (for example iCloud Drive); a JSON backup is written there once a day.

The privacy policy is also available in the app: ⋮ → 隱私權政策 (Privacy Policy).

The app's interface is in Traditional Chinese.
