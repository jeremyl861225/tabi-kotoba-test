液態金屬與分頁列試看

正式版已經換上「毛玻璃分頁列＋浮起來的紅球」。這頁試兩件事：開場的紅圓要不要用 liquid-logo 的液態金屬質感，以及分頁列的球要不要換成液態金屬。每一格都是實際在跑的畫面。

一、開場（liquid-logo 液態金屬）

A 是現在的日の丸紅圓。B 把整顆紅圓變成流動的紅色金屬；C 紅圓不動，只有「旅」字變成銀色液態金屬（liquid-logo 原本就是把標誌變成金屬）。

另外兩個沒放進來的：
・react-three-fiber 是 3D 場景（Three.js），要把整個 App 改成 React 並加上建置步驟，下載量多約 600 KB；單字卡沒有適合放 3D 物件的地方，也違反「不放插圖」。
・kokonut ui 是 React＋Tailwind＋Framer Motion 的元件集，不能直接放進這個純 JavaScript 的 App；這次分頁列的動態（滑動、拉長、圖示升起）就是照它那一類元件的做法手寫的。
・liquid-glass-js 要先用 html2canvas 把整頁拍成圖再用 WebGL 折射，捲動時會跟不上、手機很耗電，所以分頁列的玻璃改用瀏覽器內建的毛玻璃（iPhone 原生支援）。
