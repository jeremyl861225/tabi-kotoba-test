# 小鎮 · 風格試作 v3（有機街道）

使用者 10-24 看完 v2 後的要求：要有 Townscaper 的感覺；道路不一定是方形（可以有五邊形、三角形）；可以自己蓋路；河流太假。

## 做法
| 檔 | 內容 |
|---|---|
| `grid.js` | 有機網格：六角範圍的三角網 → 隨機兩兩合成四邊形、部分三角併進鄰居成五邊形 → 把每個 n 邊形往同大小的正 n 邊形拉（鬆弛 80 次）。保留三角形與五邊形，不細分 |
| `land.js` | 連續高度場（一邊山、一邊海）＋河：河道是一條蜿蜒的樣條線，水位沿途只降不升、入海處為 0；河道刻進高度場、兩側是緩坡谷地；岸線由地形和水面自然相交切出。水面著色器：法線擾動順著流向流動、岸邊與急流白浪、天空反射；海浪與沙灘浪花 |
| `warp.js` | 把在單位正方形裡設計的歐式建築，用雙線性內插變形貼進任意四邊形格子（法線用雅可比矩陣修正）；多格建築逐格分段貼 |
| `town.js` | 格子分類（陸地／河／海／太陡）、廣場、沿方向蜿蜒的街道、橋址、建築選址、分級、合併（雙併＝左右相鄰；莊園＝往後推算後半部，蓋到的格子要是空地／後院／房子）、田、後院、樹；路面（著色器畫卵石）、石拱橋、斜坡上的石砌地基 |
| `main.js` | 工具列：升級／蓋房（只有四邊形能蓋）／鋪路（可拖曳，沿路徑補格）／拆除；水上的路先是木棧道，接通兩岸改成石拱橋 |

## 已知取捨
- 只有四邊形能蓋房子；三角形與五邊形用來鋪路、做花園後院或種樹（變形到五邊形的歐式房子會很怪）。
- 莊園的後半部是用前面兩格推算出來的，會蓋過後面那一兩格；後面空間不夠就會把深度縮成 0.72 或 0.5。
- 一張地圖桌機生成約 1.9 秒。
